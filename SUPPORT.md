# Support

Fleet is early software (0.0.x) maintained by one team, so please pick the
channel that fits.

- **A question, an idea, or "is this how it should work?"**: open a
  [Discussion](https://github.com/eggs-gd/fleet.eggs.gd/discussions).
- **Something is broken**: open a
  [bug report](https://github.com/eggs-gd/fleet.eggs.gd/issues/new/choose).
  Include your OS, the Fleet version (`fleet version`), which agent was involved,
  and the log lines around the failure. Remove anything private first.
- **A security problem**: do not open an issue. Follow [SECURITY.md](SECURITY.md).
- **Conduct**: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before asking, the README section "When something does not work" covers the most
common first-run problems (dry-run mode, a busy port, a missing build).
