# Data

Your own operating data: raw inputs, projects/tasks, worker definitions,
archive, and the generated project registry. Bootstrapped automatically by
Core on first run — see `AGENTS.md` for the rules Core itself follows here.

## Shape

```text
Data
|-- Inbox/       raw incoming items before classification
|-- Work/        project/workspace folders with metadata, tasks, notes, decisions
|-- Fleet/       workers: humans, AI agents, tools, and execution surfaces
|-- Archive/     closed, superseded, or intentionally ignored material
|-- _registry/   deterministic machine-readable state generated by Core's scan
|-- _docs/       your own decisions and operating notes
|-- AGENTS.md    canonical agent instruction file for this tree
|-- .mcp.json    Fleet MCP for Claude
|-- .codex/      Fleet MCP and Manager skills for Codex
|-- .agents/     Fleet MCP for Gemini, plus the canonical Manager skills
|-- .claude/     Manager skills for Claude
|-- .gemini/     Manager skills for Gemini
`-- .cursor/     Fleet MCP and Manager rules for Cursor
```

This template is the generic bootstrap. An operator's Data copy may diverge from it. The human profile here is `owner`; an existing Data root may still use `alex`. Aligning worker notes between the two trees is not required for bootstrap.

The Manager is a Claude, Codex, Cursor, or Gemini session whose folder is
this directory. The conversation stays in that provider's app. Each provider
loads Fleet MCP from its own file above. `core serve` must be running.

Core is pointed at this directory with `--root`, a saved app config, or its
default location — see the app's own Settings for how to view or change it.
