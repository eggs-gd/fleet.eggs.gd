# Owner

The human operator of this workspace. Rename this file and the `owner`
assignee value to your own name/slug if you prefer — nothing else in this
tree hardcodes the literal word `owner`.

## Best At

- Final product decisions.
- Confirming project meaning, aliases, cleanup rules, and priorities.
- Supplying missing personal/project context.
- Choosing when a task should be handed to a specific AI worker.

## Use For

- decisions that require owner judgment;
- blocked tasks needing confirmation;
- facts that should not be guessed.
