# Claude

## Best At

- Discovery-style project work available to the user.
- Product/spec reasoning.
- Writing and shaping longer documents.
- Reviewing concepts, architecture, UX, and decisions.
- Maintaining continuity on a project when already active there.

## Use For

- `research`
- `review`
- `decision`
- project-specific work when Claude is already the active worker.

## Avoid As Default For

- local repo implementation requiring tight filesystem/test loops, unless the
  project is already Claude-led or the user explicitly assigns it.
